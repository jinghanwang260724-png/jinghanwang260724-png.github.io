# How I See — Jinghan Wang

Personal portfolio, final local preview v7.

Intended website: https://jinghanwang260724-png.github.io/

This is a static website. Publish the `main` branch, root folder, with GitHub Pages.
No build command or npm installation is required. The contact postcard opens an email
client; it does not send or store messages on a server.

Local fonts, images and animations are included. Source and asset acknowledgments
are in `credits.html` and `vendor/GSAP-NOTICE.txt`. Personal writing and photographs
are not offered under an open-source license.
